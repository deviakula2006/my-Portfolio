## Running the Project Locally

To run this portfolio locally:

git clone https://github.com/deviakula2006/my-Portfolio.git
cd my-Portfolio

Open the index.html file directly, or run using a Live Server extension in Visual Studio Code.

## Deployment

This portfolio is deployed using GitHub Pages.

To redeploy after updates:

git add .
git commit -m "Updated portfolio"
git push origin main

Enable GitHub Pages in repository settings if not already configured.
